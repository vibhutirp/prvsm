# PrVSM

## Run the demo

Open `index.html` in a browser (Chrome, straight from disk — no install, server, or network needed).
The whole demo is one zoomable office canvas: click a cubicle or the whiteboard (or press `1` / `2` / `3`) to fly into its board, `0` to fly back out; scroll zooms, drag pans. **Sync** proposes changes to the shared whiteboard.
**Reset** restores the seed state; a page reload does the same (nothing is persisted).
